# Invitation Nation QA Automation

### QA Automation Assessment – Overview

This assessment focuses on automating functional testing for the Invitation Nation website using **Python and Selenium WebDriver**. The main objective is to verify important user flows such as login, navigation through the Invitations section, selecting invitation templates, and opening the Live Demo. The automation scripts interact with web elements, handle browser tabs, wait for dynamic elements, and validate expected results. Test execution results can also be recorded in **Google Sheets**, providing a simple way to track PASS/FAIL status, execution time, and failure details. Overall, the assessment demonstrates practical knowledge of web automation, test-case implementation, exception handling, and basic QA reporting.
